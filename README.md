# Crit & Cast

A turn-based tactical roguelike on a grid, with TTRPG-style rules: classes, d20 rolls, stats, melee and spells.

Pick a class, fight battles, level up, visit the shop, and build your character over a run.

> 🚧 Early development

## Running the project

1. Install [Godot 4.7](https://godotengine.org/download).
2. Clone the repository:
   ```bash
   git clone https://github.com/Prosdocimo0/crit-and-cast.git
   ```
3. In the Godot Project Manager, click **Import** and select `project.godot`.
4. Press **F5** to run.
